# Visual Lobe: Environmental Awareness Engine

## Overview
The **Visual Lobe** acts as the NeuroSwarm's sensory gateway to the digital environment. In a biomimetic CLI architecture, "vision" is defined as the continuous observation of the system's state, workspace structure, and terminal context. It transforms raw environmental data into **Visual Engrams**.

## Technical Specification

### 1. Functional Role
The Visual Lobe is a proactive sensory organ. It periodically polls the environment to detect changes in the workspace (files created, modified, or deleted) and system health. Unlike the **Motor Lobe** (which acts), the Visual Lobe **observes** without intent, feeding raw stimuli to the **Thalamus**.

### 2. Sensory Modalities
Currently, the Visual Lobe implements the following "Retinal Scans":
- **Workspace Scan:** Recursive analysis of the directory structure to maintain a map of the "Digital Field."
- **State Change Detection:** Monitoring for unexpected external changes (e.g., manual file edits by the human user).
- **Contextual Vision:** Capturing the current "View" (e.g., last $N$ lines of a log or terminal output).

### 3. Visual Engram Protocol
Stimuli generated by this lobe are tagged with `origin: visual_lobe`.
```json
{
  "cid": "sensory_stream_...",
  "origin": "visual_lobe",
  "intent": "visual_stimulus",
  "payload": {
    "view_type": "directory_map",
    "data": "..."
  }
}
```

## Engineering Standards
- **Low Latency:** Optimized scanning algorithms to ensure the "Retinal Refresh Rate" does not consume excessive CPU.
- **Asynchronous Reporting:** Sensory data is pushed to the bus without waiting for acknowledgment, mirroring biological afferent nerves.
- **Noise Filtering:** Implements delta-tracking to only report significant changes, preventing "Neural Saturation."
